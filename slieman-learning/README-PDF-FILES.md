## 🔧 طرق التحويل السريعة / Quick Conversion Methods

### الطريقة 1: استخدام الموقع (الأسرع!) ⚡

#### للملفات Markdown:

**الخطوات:**
1. افتح: **https://www.markdowntopdf.com**
2. افتح الملف `.md` في Notepad
3. **اضغط Ctrl+A** (تحديد الكل)
4. **اضغط Ctrl+C** (نسخ)
5. الصق في الموقع (Ctrl+V)
6. اضغط **"Convert to PDF"**
7. **حمّل الملف**

**مواقع بديلة:**
- https://md2pdf.netlify.app
- https://dillinger.io (Export → PDF)
- https://www.browserling.com/tools/markdown-to-pdf

---

### الطريقة 2: استخدام VS Code Extension

**الخطوات:**
1. افتح VS Code
2. اضغط **Ctrl+Shift+X** (Extensions)
3. ابحث عن: **"Markdown PDF"**
4. ثبّت Extension من: **yzane.markdown-pdf**
5. افتح الملف `.md`
6. اضغط **Ctrl+Shift+P**
7. اكتب: **"Markdown PDF: Export (pdf)"**
8. اضغط Enter

**بديل آخر:**
- Extension: **"Markdown All in One"**
- ثم: Right-click → Print current document to HTML

---

### الطريقة 3: استخدام Microsoft Word

**الخطوات:**
1. افتح الملف `.md` في VS Code أو Notepad
2. **Ctrl+A** ثم **Ctrl+C** (نسخ الكل)
3. افتح Microsoft Word
4. **Ctrl+V** (لصق)
5. **File → Save As → PDF**

---

### الطريقة 4: استخدام Chrome (للملف HTML الموجود)

**للملف QUIZ-CORRECTION.html:**
1. Double-click على `QUIZ-CORRECTION.html`
2. سيفتح في Chrome
3. اضغط **Ctrl+P**
4. اختر **"Save as PDF"**
5. ✅ تفعيل **"Background graphics"**
6. اضغط **Save**
