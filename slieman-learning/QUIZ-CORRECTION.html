📝 أمثلة على الأخطاء الشائعة

خطأ شائع #1: Route Parameters
❌ الخطأ:
Route::get('/product/${id}', ...)
✅ الصحيح:
Route::get('/product/{id}', ...)

التوضيح: Laravel تستخدم {param} وليس ${param}

خطأ شائع #2: Route Groups
❌ الخطأ:
Route::prefix('api', function(){...})
✅ الصحيح:
Route::prefix('api')->group(function(){...})

التوضيح: استخدم method chaining مع ->group()

خطأ شائع #3: compact() Function
❌ الخطأ:
compact($product)
✅ الصحيح:
compact('product')

التوضيح: compact() يأخذ اسم المتغير كـ string وليس المتغير نفسه!

خطأ شائع #4: Controller Methods
❌ الخطأ:
public function store()
{
    $request->validate([...]);
}
✅ الصحيح:
public function store(Request $request)
{
    $request->validate([...]);
}

التوضيح: لا تنسى إضافة Request $request في parameters!
