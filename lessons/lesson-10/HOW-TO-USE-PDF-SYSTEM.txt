TROUBLESHOOTING:
----------------
Q: Server won't start?
A: Make sure you're in the correct directory and PHP is installed

Q: Can't access the PDFs?
A: Make sure the server is running (you should see "Server running...")

Q: PDF shows errors?
A: Try clearing cache: php artisan config:clear

Q: Want to regenerate PDFs?
A: Just refresh the URL - PDFs are generated on-the-fly
