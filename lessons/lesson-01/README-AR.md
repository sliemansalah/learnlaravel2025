## ما هو Laravel؟

Laravel هو **إطار عمل حديث لتطبيقات الويب بلغة PHP** مع صياغة أنيقة ومعبرة. تم إنشاؤه بواسطة Taylor Otwell في عام 2011 وأصبح واحداً من أكثر أطر عمل PHP شعبية في العالم.

### الميزات الرئيسية:
- **صياغة أنيقة**: كود نظيف وقابل للقراءة وممتع في الكتابة
- **معمارية MVC**: نمط Model-View-Controller لتنظيم الكود
- **أدوات مدمجة**: المصادقة، التوجيه، الجلسات، التخزين المؤقت جاهزة للاستخدام
- **Eloquent ORM**: تفاعلات جميلة مع قاعدة البيانات
- **قوالب Blade**: محرك قوالب قوي
- **أداة Artisan**: أداة سطر أوامر للمهام الشائعة
- **نظام بيئي كبير**: حزم مثل Sanctum, Horizon, Telescope, إلخ

---

## لماذا تختار Laravel؟

### 1. **تجربة المطور**
- توثيق واضح وشامل
- صياغة بديهية ومعبرة
- مجتمع كبير وداعم

### 2. **الأمان**
- حماية مدمجة ضد SQL Injection
- حماية من CSRF (التزوير عبر المواقع)
- منع XSS (البرمجة النصية عبر المواقع)
- تشفير آمن لكلمات المرور

### 3. **الأداء**
- آليات تخزين مؤقت مدمجة
- أدوات تحسين الاستعلامات
- قوائم انتظار للمهام الثقيلة

### 4. **قابلية التوسع**
- مستخدم من الشركات الناشئة الصغيرة إلى المؤسسات الكبيرة
- دعم الخدمات الصغيرة (Microservices)
- إمكانيات التوسع الأفقي

## هيكل مشروع Laravel

عندما تنظر إلى مشروع Laravel، سترى هذا الهيكل:

```
laravel-project/
├── app/                    # كود التطبيق الأساسي
│   ├── Http/
│   │   ├── Controllers/    # فئات المتحكمات
│   │   └── Middleware/     # البرمجيات الوسيطة
│   ├── Models/             # نماذج Eloquent
│   └── Providers/          # موفرو الخدمات
├── bootstrap/              # ملفات تحميل الإطار
├── config/                 # ملفات الإعدادات
├── database/
│   ├── migrations/         # هجرات قاعدة البيانات
│   ├── seeders/            # بذور قاعدة البيانات
│   └── factories/          # مصانع النماذج
├── public/                 # الملفات العامة
│   └── index.php           # نقطة الدخول
├── resources/
│   ├── views/              # قوالب Blade
│   ├── css/                # ملفات CSS
│   └── js/                 # ملفات JavaScript
├── routes/
│   ├── web.php             # مسارات الويب
│   ├── api.php             # مسارات API
│   └── console.php         # أوامر Console
├── storage/                # السجلات، التخزين المؤقت، الملفات المرفوعة
├── tests/                  # الاختبارات الآلية
├── vendor/                 # تبعيات Composer
├── .env                    # متغيرات البيئة
├── artisan                 # أداة Artisan CLI
└── composer.json           # تبعيات PHP
```

### شرح المجلدات المهمة:

| المجلد | الغرض |
|--------|--------|
| **app/** | يحتوي على كود التطبيق الأساسي (النماذج، المتحكمات، البرمجيات الوسيطة) |
| **config/** | جميع ملفات الإعدادات (قاعدة البيانات، البريد، التخزين المؤقت، إلخ) |
| **database/** | هجرات قاعدة البيانات، البذور، والمصانع |
| **public/** | نقطة الدخول لجميع الطلبات، يحتوي على الملفات العامة |
| **resources/views/** | ملفات قوالب Blade |
| **routes/** | تعريف جميع نقاط النهاية للتطبيق |
| **storage/** | قوالب Blade المجمعة، الملفات المرفوعة، السجلات، التخزين المؤقت |

## تطبيق Laravel الأول

### الخطوة 1: تحقق من بيئتك

تأكد من وجود:
- PHP >= 8.1
- Composer (مدير حزم PHP)
- MySQL/PostgreSQL/SQLite (قاعدة بيانات)

تحقق من الإصدارات:
```bash
php -v
composer -v
```

### الخطوة 2: فهم المشروع الحالي

أنت الآن في مشروع Laravel! دعنا نستكشف ما هو موجود.

#### نقطة الدخول
كل طلب يمر عبر `public/index.php`، والذي:
1. يحمّل محمل التلقائي (autoloader)
2. يبدأ التطبيق
3. يعالج الطلب
4. يعيد الاستجابة

#### الإعدادات
ملف `.env` يحتوي على إعدادات خاصة بالبيئة:
```
APP_NAME=Laravel
APP_ENV=local
APP_DEBUG=true
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
```

**مهم**: لا تضف ملف `.env` إلى نظام التحكم بالإصدارات! يحتوي على بيانات حساسة.

### الخطوة 3: Artisan - صديقك المفضل

Laravel يأتي مع **Artisan**، أداة قوية لسطر الأوامر.

جرب هذه الأوامر:
```bash
# قائمة جميع الأوامر المتاحة
php artisan list

# تحقق من إصدار Laravel
php artisan --version

# عرض المسارات
php artisan route:list

# بدء خادم التطوير
php artisan serve
```

الأمر `php artisan serve` يبدأ خادم تطوير محلي على `http://localhost:8000`.

## فهم دورة حياة الطلب

هذا ما يحدث عندما يزور مستخدم تطبيق Laravel الخاص بك:

```
1. طلب المستخدم
   ↓
2. public/index.php (نقطة الدخول)
   ↓
3. بدء Laravel
   ↓
4. تحميل موفري الخدمات
   ↓
5. التوجيه (routes/web.php أو routes/api.php)
   ↓
6. البرمجيات الوسيطة (الأمان، المصادقة، إلخ)
   ↓
7. المتحكم (منطق الأعمال)
   ↓
8. النموذج (التفاعل مع قاعدة البيانات) - إذا لزم الأمر
   ↓
9. العرض (قالب Blade) - لطلبات الويب
   ↓
10. إرسال الاستجابة إلى المستخدم
```

### مثال على التدفق:

**المستخدم يزور**: `http://yourapp.com/welcome`

1. **المسار** (`routes/web.php`):
```php
Route::get('/welcome', function () {
    return view('welcome');
});
```

2. **العرض** (`resources/views/welcome.blade.php`):
```html
<!DOCTYPE html>
<html>
<head>
    <title>مرحباً</title>
</head>
<body>
    <h1>مرحباً بك في Laravel!</h1>
</body>
</html>
```

3. **الاستجابة**: يتم عرض HTML وإرساله إلى المتصفح

## التمارين العملية

### التمرين 1: استكشف مشروعك ✅

افتح مشروع Laravel الخاص بك وحدد:
- [ ] أين نقطة الدخول الرئيسية؟ (تلميح: `public/index.php`)
- [ ] أين يتم تعريف المسارات؟ (تلميح: `routes/web.php`)
- [ ] أين يتم تخزين العروض؟ (تلميح: `resources/views/`)
- [ ] ماذا يوجد في ملف `.env`؟

### التمرين 2: ابدأ خادم التطوير

```bash
php artisan serve
```

زر `http://localhost:8000` في متصفحك. ماذا ترى؟

### التمرين 3: أنشئ مسارك الأول

1. افتح `routes/web.php`
2. أضف هذا المسار الجديد:

```php
Route::get('/hello', function () {
    return '<h1>مرحباً، أنا أتعلم Laravel!</h1>';
});
```

3. زر `http://localhost:8000/hello`

**التحدي**: أنشئ مسارات لـ:
- `/about` - يعيد صفحة "عني"
- `/contact` - يعيد صفحة "اتصل بنا"

### التمرين 4: استكشف أوامر Artisan

نفذ هذه الأوامر ولاحظ النتائج:

```bash
# قائمة جميع المسارات
php artisan route:list

# مسح التخزين المؤقت
php artisan cache:clear

# عرض جميع أوامر artisan
php artisan list
```

### التمرين 5: أنشئ عرضاً بسيطاً

1. أنشئ ملفاً جديداً: `resources/views/mypage.blade.php`

```html
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
    <title>صفحتي الأولى</title>
    <style>
        body {
            font-family: Arial, sans-serif;
            max-width: 800px;
            margin: 50px auto;
            text-align: center;
        }
        h1 {
            color: #FF2D20;
        }
    </style>
</head>
<body>
    <h1>صفحتي الأولى في Laravel</h1>
    <p>أنا أتعلم Laravel خطوة بخطوة!</p>
    <p>التاريخ الحالي: {{ date('Y-m-d H:i:s') }}</p>
</body>
</html>
```

2. أنشئ مساراً له في `routes/web.php`:

```php
Route::get('/mypage', function () {
    return view('mypage');
});
```

3. زر `http://localhost:8000/mypage`
