## 📚 المجموعة الأولى: Middleware الأساسية

### تمرين 1: Age Verification Middleware

**الهدف:** إنشاء Middleware للتحقق من العمر

**المتطلبات:**
- أنشئ Middleware باسم `CheckAge`
- إذا كان عمر المستخدم أقل من 18، أعد توجيهه لصفحة "underage"
- طبق هذا الـ Middleware على route `/adult-content`

**خطوات التنفيذ:**
1. أنشئ الـ Middleware: `php artisan make:middleware CheckAge`
2. أضف منطق التحقق من العمر
3. سجل الـ Middleware في `bootstrap/app.php`
4. أنشئ route وطبق عليه الـ Middleware
5. أنشئ view بسيط للاختبار

**معايير النجاح:**
- [ ] يتم رفض المستخدمين أقل من 18
- [ ] يتم السماح للمستخدمين 18 فما فوق
- [ ] رسالة خطأ واضحة للمرفوضين

---

### تمرين 2: IP Whitelist Middleware

**الهدف:** السماح فقط لـ IP addresses محددة

**المتطلبات:**
- أنشئ Middleware باسم `CheckIpWhitelist`
- احفظ قائمة IPs مسموحة في config file
- إذا لم يكن IP المستخدم في القائمة، أعد توجيهه لصفحة "access-denied"

**خطوات التنفيذ:**
1. أنشئ config file: `config/security.php`
2. أضف قائمة الـ IPs المسموحة
3. أنشئ الـ Middleware
4. اختبره بإضافة وإزالة IPs

**معايير النجاح:**
- [ ] فقط IPs في القائمة يمكنهم الوصول
- [ ] رسالة خطأ مناسبة للمرفوضين
- [ ] سهولة تحديث قائمة الـ IPs

---

### تمرين 3: Request Logger Middleware

**الهدف:** تسجيل جميع الطلبات

**المتطلبات:**
- أنشئ Middleware لتسجيل معلومات الطلب
- سجل: URL، Method، IP، User Agent، Timestamp
- احفظ السجلات في ملف log

**خطوات التنفيذ:**
1. أنشئ Middleware: `php artisan make:middleware LogRequests`
2. استخدم `Log` facade للتسجيل
3. سجله كـ Global Middleware
4. اختبر بعدة طلبات

**معايير النجاح:**
- [ ] جميع الطلبات يتم تسجيلها
- [ ] المعلومات كاملة ودقيقة
- [ ] تنسيق واضح للسجلات

---

### تمرين 4: Response Time Middleware

**الهدف:** قياس وقت الاستجابة لكل طلب

**المتطلبات:**
- قس الوقت المستغرق لمعالجة الطلب
- أضف header يحتوي على وقت الاستجابة
- سجل الطلبات البطيئة (أكثر من 1 ثانية)

**خطوات التنفيذ:**
1. أنشئ Middleware: `MeasureResponseTime`
2. استخدم `microtime()` لقياس الوقت
3. أضف custom header
4. سجل التحذيرات للطلبات البطيئة

**معايير النجاح:**
- [ ] يتم قياس الوقت بدقة
- [ ] Header موجود في كل response
- [ ] تسجيل الطلبات البطيئة

---

### تمرين 5: JSON Only API Middleware

**الهدف:** التأكد من أن الطلبات API تقبل JSON فقط

**المتطلبات:**
- تحقق من `Accept: application/json` header
- إذا لم يكن موجوداً، أرجع error 406 (Not Acceptable)
- طبقه على routes API

**خطوات التنفيذ:**
1. أنشئ Middleware: `EnsureJsonRequest`
2. تحقق من Accept header
3. طبقه على API routes group

**معايير النجاح:**
- [ ] رفض الطلبات بدون JSON header
- [ ] رسالة خطأ بصيغة JSON
- [ ] يعمل على جميع API routes

## 💡 نصائح للنجاح

1. **ابدأ بالسهل:** لا تقفز للتمارين الصعبة مباشرة
2. **اختبر كل خطوة:** لا تنتظر حتى النهاية للاختبار
3. **اقرأ الأخطاء:** رسائل الأخطاء تعطيك معلومات قيمة
4. **استخدم Debugger:** dd(), dump() أصدقاؤك
5. **راجع النظرية:** إذا نسيت شيئاً، ارجع للملفات النظرية
6. **لا تنسخ:** حاول الكتابة بنفسك لتتعلم أكثر
7. **اطلب المساعدة:** إذا علقت أكثر من 30 دقيقة
