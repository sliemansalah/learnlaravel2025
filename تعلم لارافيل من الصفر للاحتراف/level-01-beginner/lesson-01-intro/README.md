## 🐛 حل المشاكل الشائعة

### مشكلة 1: خطأ في تثبيت Composer

**الأعراض:**
```
composer: command not found
```

**الحل:**
```bash
# تأكد من إضافة Composer إلى PATH
# Windows: أعد تشغيل CMD
# macOS/Linux: أعد تحميل .bashrc أو .zshrc
```

### مشكلة 2: خطأ في Extensions

**الأعراض:**
```
Class "PDO" not found
```

**الحل:**
```
1. افتح ملف php.ini
2. ابحث عن:extension=pdo_mysql
3. احذف ; من بداية السطر
4. احفظ وأعد تشغيل الخادم
```

### مشكلة 3: Permission Denied

**الأعراض (macOS/Linux):**
```
Permission denied
```

**الحل:**
```bash
chmod -R 775 storage bootstrap/cache
```

### للمزيد:
راجع ملف `resources/troubleshooting.md`
