2. اقرأ التعليقات بعناية
3. انسخ الكود إلى ملفات مشروعك المناسبة
4. شغّل التطبيق وجرّب

1. اقرأ المثال وافهم فكرته
2. **لا تنسخ** - اكتب الكود بنفسك
3. جرّب وعدّل
4. قارن مع المثال الأصلي

## ❓ مشاكل شائعة

### المشكلة 1: الصفحة لا تظهر

**السبب:** قد تكون نسيت حفظ الملف

**الحل:**
```
1. احفظ الملف (Ctrl+S / Cmd+S)
2. حدّث المتصفح (F5)
```

### المشكلة 2: خطأ في الـ Route

**السبب:** قد يكون هناك خطأ في كتابة اسم الـ route

**الحل:**
```bash
# راجع قائمة جميع الـ routes
php artisan route:list
```
