## 🔧 حل المشاكل

### المشكلة 1: CSS لا يظهر

**السبب:** مسار نسبي خاطئ

**الحل:**
- استخدم server محلي (Python/PHP)
- أو افتح `index.html` من المجلد مباشرة

### المشكلة 2: الروابط لا تعمل

**السبب:** بعض المتصفحات تمنع JavaScript المحلي

**الحل:**
```bash
# استخدم server
python -m http.server 8000
# ثم افتح: http://localhost:8000
```

### المشكلة 3: الخطوط غير واضحة

**الحل:**
- استخدم Zoom: Ctrl/Cmd + Plus
- أو غيّر font-size في المتصفح
