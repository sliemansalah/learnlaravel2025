========================================
   كيفية فتح المحتوى
   How to Open Content
========================================

🚀 الطريقة الأسهل:
   Simply Open: index.html

📖 أو افتح أي من هذه الملفات:
   - index.html (الصفحة الرئيسية)
   - README.html (دليل الدرس)
   - 01-theory.html (الدرس النظري)
   - 02-practice.html (العملي)

========================================
   للحصول على أفضل تجربة
   For Best Experience
========================================

استخدم Server محلي:

💻 Python:
   cd html
   python -m http.server 8000
   ثم افتح: http://localhost:8000

💻 PHP:
   cd html
   php -S localhost:8000
   ثم افتح: http://localhost:8000

💻 Node.js:
   npx http-server html
   ثم افتح: http://localhost:8080
