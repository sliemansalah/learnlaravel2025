الطريقة الأولى: نسخ الكود مباشرة

  1. افتح المثال المطلوب
  2. اقرأ التعليقات بعناية
  3. انسخ الكود إلى ملفات مشروعك المناسبة
  4. شغّل التطبيق وجرّب

الطريقة الثانية: فهم ثم كتابة

  1. اقرأ المثال وافهم فكرته
  2. لا تنسخ - اكتب الكود بنفسك
  3. جرّب وعدّل
  4. قارن مع المثال الأصلي

Example 02 - Views

💡 نصائح

✅ افعل:

  • اقرأ التعليقات في الكود
  • جرّب تعديل القيم
  • شغّل كل مثال على حدة
  • اكتب الكود بنفسك

❌ لا تفعل:

  • لا تنسخ ولصق بدون فهم
  • لا تتخطى أي مثال
  • لا تنسى حفظ الملفات

🔧 كيفية التشغيل

بعد نسخ الكود:

# تأكد أنك في مجلد المشروع
cd my-first-laravel-app

# شغّل السيرفر
php artisan serve

# افتح المتصفح
# http://localhost:8000

❓ مشاكل شائعة

المشكلة 1: الصفحة لا تظهر

السبب: قد تكون نسيت حفظ الملف

الحل:

1. احفظ الملف (Ctrl+S / Cmd+S)
2. حدّث المتصفح (F5)

المشكلة 2: خطأ في الـ Route

السبب: قد يكون هناك خطأ في كتابة اسم الـ route

الحل:

# راجع قائمة جميع الـ routes
php artisan route:list
