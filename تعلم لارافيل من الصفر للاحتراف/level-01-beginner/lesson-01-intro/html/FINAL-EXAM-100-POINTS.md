#### 3. مقالية قصيرة (2 سؤال × 5 نقاط = 10 نقاط)

**طريقة التصحيح المقالي:**

- نظام تقييم ذكي:

### القسم الثالث: التطبيقي (30 نقطة)
مشروع واحد متكامل مقسم إلى 5 خطوات

#### المشروع: إنشاء صفحة "من نحن" (About Us) كاملة

**الخطوة 1** (5 نقاط): كتابة Route للمسار '/about'
```php
Route::get('/about', function() {
    return view('about');
});
```

**الخطوة 2** (10 نقاط): كتابة Blade View كامل
- يجب أن يحتوي على عنوان
- فقرة عن الموقع
- عرض Laravel version
- رابط للعودة

**الخطوة 3** (5 نقاط): أمر إنشاء PageController
```bash
php artisan make:controller PageController
```

**الخطوة 4** (5 نقاط): كتابة method في Controller
```php
public function about() {
    return view('about');
}
```

**الخطوة 5** (5 نقاط): Route محدّث يستخدم Controller
```php
Route::get('/about', [PageController::class, 'about']);
```

**طريقة تصحيح المشروع:**
- كل خطوة تُصحح بشكل مستقل
- يستخدم Regular Expressions لمطابقة الأنماط
- يعرض الحل النموذجي لكل خطوة
- الدرجة النهائية = مجموع درجات الخطوات الخمس
