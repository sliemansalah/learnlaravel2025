🚀 البدء السريع

الطريقة الأسهل:

# 1. افتح مجلد html
cd html

# 2. استخدم Python لتشغيل server محلي
python -m http.server 8000

# 3. افتح المتصفح
# http://localhost:8000

أو:

# افتح الملف مباشرة
start html/index.html      # Windows
open html/index.html       # macOS
xdg-open html/index.html   # Linux

🔄 إعادة التحويل (إذا عدّلت .md)

إذا قمت بتعديل أي ملف Markdown وتريد تحديث HTML:

# استخدم المحول المحسّن
node convert-improved.js

سيتم تحديث جميع ملفات HTML تلقائياً! ✨

💡 نصائح الاستخدام

للقراءة:

  1. ✅ افتح index.html أولاً - يحتوي على جميع الروابط
  2. ✅ استخدم القائمة العلوية - للتنقل السريع
  3. ✅ Ctrl+F للبحث - ابحث عن أي كلمة
  4. ✅ انقر على العناوين - للانتقال المباشر

للتعلم:

  1. ✅ ابدأ بالترتيب (README → Theory → Practice)
  2. ✅ افتح عدة tabs للمقارنة
  3. ✅ انسخ الأكواد وجرّبها
  4. ✅ استخدم Ctrl+P للطباعة أو حفظ PDF

للطباعة:

1. Ctrl/Cmd + P
2. اختر "حفظ كـ PDF"
3. فعّل "Background graphics"
4. احفظ الملف

🔧 حل المشاكل

المشكلة 1: CSS لا يظهر

السبب: مسار نسبي خاطئ

الحل:

  • استخدم server محلي (Python/PHP)
  • أو افتح index.html من المجلد مباشرة

المشكلة 2: الروابط لا تعمل

السبب: بعض المتصفحات تمنع JavaScript المحلي

الحل:

# استخدم server
python -m http.server 8000
# ثم افتح: http://localhost:8000

المشكلة 3: الخطوط غير واضحة

الحل:

  • استخدم Zoom: Ctrl/Cmd + Plus
  • أو غيّر font-size في المتصفح

🎯 اختبار سريع

افتح الملفات التالية للتأكد أن كل شيء يعمل:

  1. ✅ html/index.html - الصفحة الرئيسية
  2. ✅ html/01-theory.html - الدرس النظري
  3. ✅ html/resources/cheatsheet.html - ورقة الغش
  4. ✅ html/exercises/exercise-01-problem.html - تمرين

إذا فتحت جميعها بنجاح - تهانينا! كل شيء يعمل! 🎉
