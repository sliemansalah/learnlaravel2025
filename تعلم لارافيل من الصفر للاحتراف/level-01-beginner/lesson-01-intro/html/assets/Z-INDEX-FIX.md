# إصلاح مشكلة z-index لجدول المحتويات

## التاريخ: 2025-11-03

## المشكلة المبلغ عنها

جدول المحتويات (Table of Contents) كان يظهر **فوق محتوى الصفحة** أثناء القراءة، مما يعيق القراءة ويخفي النصوص.

### السبب:
```css
/* القيم القديمة - المشكلة */
.table-of-contents {
  position: sticky;    /* يبقى عالقاً في الشاشة */
  top: 80px;
  z-index: 100;       /* قيمة عالية جداً! */
}
```

**المشاكل:**
- ❌ `position: sticky` يجعله عالقاً فوق المحتوى أثناء التمرير
- ❌ `z-index: 100` أعلى من المحتوى العادي
- ❌ يتداخل مع النصوص ويخفيها
- ❌ صعوبة في القراءة

## الحل المطبق ✅

### 1. تغيير Position من Sticky إلى Relative

```css
/* القيم الجديدة - الحل */
.table-of-contents {
  position: relative;  /* ✅ لا يعوم فوق المحتوى */
  margin: 30px 0;     /* ✅ مسافات طبيعية */
  max-height: 500px;  /* ✅ ارتفاع ثابت ومعقول */
  z-index: 1;         /* ✅ قيمة منخفضة جداً */
}
```

### 2. إزالة خاصية top

لم تعد مطلوبة لأن position أصبح relative.

### 3. تقليل max-height

- **قبل:** `calc(100vh - 120px)` (قد يكون طويلاً جداً)
- **بعد:** `500px` (ارتفاع ثابت ومناسب)

### 4. تخفيض z-index بشكل كبير

- **قبل:** `z-index: 100` (عالي جداً)
- **بعد:** `z-index: 1` (منخفض ومناسب)

## مقارنة القيم

| الخاصية | قبل | بعد | الفرق |
|---------|-----|-----|-------|
| **position** | sticky | relative | ✅ لا يعوم |
| **top** | 80px | - (محذوف) | ✅ غير مطلوب |
| **margin-bottom** | 30px | margin: 30px 0 | ✅ أفضل |
| **max-height** | calc(100vh - 120px) | 500px | ✅ ثابت |
| **z-index** | 100 | 1 | ✅ منخفض |

## ترتيب z-index في الصفحة

الآن الترتيب أصبح منطقياً:

```
┌─────────────────────────────────┐
│ nav-menu (z-index: 1000) ← أعلى طبقة (sticky)
├─────────────────────────────────┤
│ المحتوى العادي (z-index: auto)
│ - الفقرات
│ - الجداول
│ - الصور
│ - الأكواد
├─────────────────────────────────┤
│ table-of-contents (z-index: 1) ← في المحتوى
├─────────────────────────────────┤
│ scrollTop button (منفصل، fixed)
└─────────────────────────────────┘
```


### 4. على الموبايل:

## البدائل المتاحة

إذا أردت العودة لـ sticky (عالق)، استخدم هذه القيم الآمنة:

```css

  position: sticky;
  top: 80px;           /* تحت nav-menu */
  z-index: 5;          /* أقل من nav-menu (1000) */
  margin-bottom: 30px;
  max-height: 400px;   /* ارتفاع محدود */
}
```

**ملاحظة:** لكن `relative` أفضل للقراءة!
